# AutoResearch Lab Index

Searchable index for lab-only experiments. Keep production/source behavior unchanged until a lab has a stable baseline, an isolated candidate result, and a separate production-integration brief.

## Lab Protocol

- Keep each experiment under `autoresearch/<lab-name>/`.
- Record baseline and candidate metrics in that lab's experiment log.
- Prefer deterministic, isolated harnesses first; use BenchmarkDotNet for stable throughput, latency, and allocation comparisons.
- Treat measured changes within 2% of baseline as noise unless the metric is deterministic by construction, such as copied bytes, operation attempts, callback counts, or dispose counts.
- For a 200-iteration loop, change one candidate variable per iteration and preserve the best passing result with command, metric, and notes.
